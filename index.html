Robin: Your eyes and hands on any Linux box you can ssh to.

robin gui <host> opens a desktop from that host in your browser. The host needs only the SSH access you already have: no server to install, no ports to open, no root.

$robin gui alice@build-box
Install How it works

What happens when you run it

Your own ssh does the connecting, so your config, keys, jump hosts and 2FA prompts work as they always do.

  1. 1 Connect ssh -M opens one connection, and the probe, the upload, the agent and the tunnel all ride it. Windows' OpenSSH has no ControlMaster, so there each opens its own.
  2. 2 Probe A shell probe reports the distro, architecture, live sessions, GPU and a directory the agent can run from.
  3. 3 Deploy The static agent for that architecture goes up over SFTP and is checked by SHA-256 before it runs.
  4. 4 Start The agent starts Xvfb and a session, or attaches to the desktop you are already logged in to.
  5. 5 Stream Video and sound reach your browser over WebRTC; keys, pointer and clipboard come back. Without UDP, it all rides SSH.

What it needs

Nothing stays running once you end the session.

The host
Linux on x86_64 or arm64 and an SSH login. For a new desktop, Xvfb and a window manager; to attach, only the desktop.
Your machine
macOS, Linux, Windows or Android in Termux, with OpenSSH and a browser that decodes H.264 in WebRTC.
If the connection drops
A desktop Robin started waits on the host for you to come back, 8 hours by default or as long as --keep says. An attached one ends with the connection unless you name a --keep.
When you end it
The agent stops everything it started and removes its run directory. Only the agent binary stays, cached for the next session, plus the restore token if you approved a Wayland share.
# a new desktop on build-box, or the one you left
$ robin gui alice@build-box

# the desktop you are logged in to
$ robin gui --attach auto workstation

# anything after -- goes to ssh
$ robin gui build-box -- -p 2222 -i ~/.ssh/other_key

# print the URL instead of opening a browser
$ robin gui --no-browser lab-node

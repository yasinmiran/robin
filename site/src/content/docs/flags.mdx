```text
robin gui [flags] [user@]host [-- ssh-args...]
robin gui --join code [flags] [user@]host [-- ssh-args...]
robin ls [user@]host [-- ssh-args...]
robin end [user@]host [id] [-- ssh-args...]
robin version
```

`robin gui` opens a desktop on the host, or picks up one the host kept for you. `robin ls` lists the sessions the host keeps, each with its id and the time it ends on its own, and `robin end` ends one without opening it (give it the id when the host keeps more than one). `robin version` prints the version. [Kept sessions](/sessions) says how they fit together.

[Using Robin](/using) shows what the flags change in a session. They take one dash or two (`-v`, `--max-size`) and go before the host, and `robin gui -h` prints the same list with its defaults, though `robin ls` and `robin end` take only `--ssh`, `--ssh-mux` and `-v`.

## Picture

<Flags>
<Flag name="--max-size" arg="WxH" def="`2560x1440`, `1920x1080` on hosts with 4 cores or fewer, `1280x720` with 2 or fewer">
Largest remote resolution, such as `1920x1080`. A new desktop follows your window up to this size; a larger attached desktop is scaled down to it.
</Flag>
<Flag name="--fps" arg="N" def="`30`, `20` on hosts with 2 cores or fewer">
Frame rate cap.
</Flag>
<Flag name="--hidpi" def="off">
Size the remote display in your screen's device pixels: sharper text on a HiDPI screen, more to encode. To see it at full size, raise `--max-size` as well.
</Flag>
<Flag name="--max-kbps" arg="N" def="`10000`">
Video bitrate ceiling, in kbit/s.
</Flag>
<Flag name="--encoder" arg="MODE" def="`auto`">
Video encoder on the host: `auto` (the GPU where the host has one that helps, else software), `software`, `vaapi` or `nvenc`. Name an encoder the host cannot run and `robin gui` stops and says what is missing. See [GPU encoding](/using#gpu-encoding).
</Flag>
</Flags>

## Desktop

<Flags>
<Flag name="--session" arg="CMD" def="the lightest desktop found">
Command to run in a new desktop, such as `startxfce4`.
</Flag>
<Flag name="--attach" arg="TARGET" def="none, a new desktop">
Show a desktop already running on the host: an X11 display such as `:0`, `auto` for your active session, or `wayland` for your Wayland session. See [Attaching to a desktop](/attach).
</Flag>
<Flag name="--monitor" arg="MONITOR" def="`primary`">
On an attached X11 desktop, the monitor to show first: a name such as `DP-1`, its number counting from 1, or `all` for every monitor as one picture. The page switches between them, and on Wayland you pick the monitor in the sharing dialog.
</Flag>
<Flag name="--audio" def="`true`">
Stream the desktop's sound. `--audio=false` leaves it out.
</Flag>
</Flags>

## Kept sessions

<Flags>
<Flag name="--keep" arg="DURATION" def="`8h`, `0` with `--attach`">
How long the host keeps the desktop after the connection drops or you detach the page, for a later `robin gui` to pick up. Give a duration such as `30m` or `8h`; `0` ends the desktop with the connection. See [Kept sessions](/sessions).
</Flag>
<Flag name="--id" arg="ID" def="the one kept session">
The kept session to resume, by the id `robin ls` prints. You need it when the host keeps more than one, and to resume a kept attached desktop.
</Flag>
<Flag name="--new" def="off">
Start a new desktop even when a kept one could be resumed.
</Flag>
</Flags>

## Microphone and camera

<Flags>
<Flag name="--mic" def="off">
Offer your microphone to the host's programs, as `Robin microphone`. It stays off until you switch it on in the page. See [Microphone and camera](/sound#microphone-and-camera).
</Flag>
<Flag name="--camera" def="off">
Offer your camera to the host's programs, through PipeWire or a `v4l2loopback` device; like the microphone, it stays off until you switch it on in the page.
</Flag>
</Flags>

## Private sessions

<Flags>
<Flag name="--curtain" def="off">
Black out the host's screen while the page still shows the desktop. It works with `--attach`, or with `--id` when you resume an attached desktop, and it does not lock the host's keyboard. See [Private sessions](/private-session).
</Flag>
<Flag name="--silent" def="off">
Keep the host's speakers quiet while the page still plays the sound. It works where `--curtain` does.
</Flag>
</Flags>

## Sharing

<Flags>
<Flag name="--share" arg="USER" def="none">
Invite this account on the host to join your session as a guest, who watches until you give them control in the page. Repeat it to invite more. See [Sharing a desktop](/sharing).
</Flag>
<Flag name="--join" arg="CODE" def="none">
Join another account's session as a guest, with the code its owner was given, logged in to the host as yourself. A guest cannot use `--share`, `--attach`, `--id`, `--new`, `--session`, `--camera`, `--curtain` or `--silent`.
</Flag>
</Flags>

## Network

<Flags>
<Flag name="--transport" arg="MODE" def="`auto`">
Media path: `auto` (direct UDP, with the SSH tunnel as fallback), `direct` for UDP only, or `tunnel` to keep the media on the SSH connection. See [Transports](/using#transports).
</Flag>
<Flag name="--stun" arg="SERVERS" def="`stun:stun.l.google.com:19302`">
Comma-separated STUN servers for NAT traversal, or `none`. `--transport tunnel` asks none.
</Flag>
<Flag name="--listen" arg="ADDR" def="`127.0.0.1:0`">
Address for the local page. It must be a loopback address; `robin gui` refuses any other.
</Flag>
</Flags>

## Client

<Flags>
<Flag name="--no-browser" def="off">
Print the page URL on stdout instead of opening a browser.
</Flag>
<Flag name="--ssh" arg="PATH" def="`ssh`">
The ssh client to run.
</Flag>
<Flag name="--ssh-mux" def="`true`, `false` on Windows">
Carry everything over one ssh ControlMaster connection; `--ssh-mux=false` gives each command its own connection, as on Windows.
</Flag>
<Flag name="-v" def="off">
Log the CLI and the agent to stderr.
</Flag>
</Flags>

## Passing options to ssh

<Flags>
<Flag name="--" arg="ssh-args...">
Flags for `robin` go before the host. Everything after `--` goes to `ssh` as it is, as in `robin gui build-box -- -p 2222`.
</Flag>
</Flags>

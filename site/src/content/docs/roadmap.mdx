Robin started as one command that put a remote desktop in a browser for as long as an SSH connection lasted. Most of what a day of working on a remote desktop needs has landed since, each part with its tests: unit tests for new code and container tests for anything that needs X, Wayland, PulseAudio or PipeWire, plus an end-to-end scenario wherever the change shows in the page.

<Callout type="note" title="Next means not built yet.">
Nothing under What is next has shipped, and names shown there may change before it does. For what Robin does now, see [Shipped](#shipped) below, [Using Robin](/using) and [Known limits](/known-limits).
</Callout>

## What is next

### A window per monitor

Today an attached desktop shows one monitor at a time, or all of them squeezed into one picture. Next, each remote monitor gets a browser window of its own, with its own picture and the bitrate shared by area, and input from each window lands on its monitor. X11 comes first, and Wayland follows if the portal's several streams can be tested.

### Coverage

Some of what ships has been checked only in part, and closing those gaps is work of its own:

- NVENC on real NVIDIA hardware, which so far runs only against stand-in tools.
- The Windows and Android clients on the real thing, which so far run in cross-builds, Chrome's phone emulation and the Linux form of the Windows mode.
- The curtain on real screens, GNOME included, which so far runs on Xvfb and against a stand-in for mutter.
- The microphone and camera in Firefox and Safari, and Safari's picture in the automated tests rather than by hand.
- Building the agents on a Mac, and checking that a Mac build gives the same bytes as a Linux one.

What does not change: Robin stays a tool for machines you can already reach over SSH, and iOS stays out, since there is no way to run the CLI there. See [Robin and Horizon](/robin-and-horizon).

## Shipped

Each of these has a page of its own:

- [Kept sessions](/sessions): a desktop Robin started outlives a dropped connection, and a later `robin gui` picks it up.
- [Microphone and camera](/microphone-and-camera): the devices of the machine you sit at, offered to the host's programs.
- [Files and the clipboard](/files-and-clipboard): uploads by a drop, downloads offered with `robin-send`, and text, HTML and images up to 16 MiB either way.
- [Private sessions](/private-session): the host's own screen dark and its speakers quiet while you work on an attached desktop.
- [Browsers and clients](/browsers): Windows and Android clients, input methods and touch.
- [Video in motion](/how-it-works#video-in-motion): a refresh twice a second instead of keyframe requests, keyframes spread over 200 ms, and 2560x1440 by default where the host has the cores.
- [Congestion control](/how-it-works#congestion-control): sound ahead of the picture, the bitrate held through a still screen, and downloads under the picture's budget.
- [Sharp text and actual size](/using#sharp-text-and-actual-size): lossless tiles over still parts of the screen, and a view that shows each desktop pixel whole.
- [Keys and macros](/macros): the keys your browser keeps for itself, Type clipboard, and macros of your own.
- [Sharing a desktop](/sharing): another account on the host invited with `robin gui --share` joins with `robin gui --join` and a one-time code, the kernel confirming the account, as a peer of its own on the one stream, view only until the owner grants control, which one guest holds at a time; clipboard, files and microphone follow control. The cross-user cases run as regression tests in the container suite and in an end-to-end scenario with an owner's page and a guest's.
- [Security](/security): a review that bounded what each side can make the other hold, kept the page's token off command lines, turned other users of a shared client away from the tunnel, and made the host agent take a session's sockets and its daemon from your own account only.
- [Verifying a release](/verifying-a-release): every binary a release ships is reproducible, so anyone with a clone can rebuild it and compare the bytes.

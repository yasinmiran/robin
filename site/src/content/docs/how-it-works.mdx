<title id="robin-arch-title">How a Robin session is wired</title>
<desc id="robin-arch-desc">On your machine, the browser talks to the robin CLI over a websocket, and the CLI drives ssh. One SSH connection reaches sshd on the Linux host, which runs robin-agent and forwards to its ICE-TCP listener. The agent captures the desktop. Media goes straight from the agent to the browser over UDP, or, when UDP is blocked, through the CLI's tunnel listener and the SSH connection.</desc>

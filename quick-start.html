Quick start

From a built robin binary to a remote desktop in your browser, and what to do when the host is missing something.

On this page
  1. 1. Open a desktop
  2. 2. If the host is missing something
  3. 3. Use it
  4. 4. Leave it, or end it
  5. When something goes wrong

This page starts from a built CLI. If you do not have one yet, run make in a checkout (see Install and build); it leaves the CLI at bin/robin, and make dist, on a release tag or with a VERSION, leaves one per client platform in dist/.

1. Open a desktop

bin/robin gui alice@build-box

The destination is whatever you would give ssh: a host alias from ~/.ssh/config, user@host, or an address. Anything after -- goes to ssh untouched:

bin/robin gui build-box -- -p 2222 -i ~/.ssh/other_key

Answer any prompt ssh puts up. The CLI then probes the host, uploads the agent if this host does not have the current one, and starts a desktop. When the desktop is up, your browser opens on a page at 127.0.0.1 and the terminal prints the display it is showing, the host, and press Ctrl+C to end the session.

2. If the host is missing something

A spawned desktop needs Xvfb, xkbcomp, a desktop or window manager, and a terminal. When any of them is missing, the CLI stops before it uploads anything and says what to install, with the command for the host’s package manager:

robin: build-box cannot run a headless desktop yet: missing Xvfb, xkbcomp, a window manager or desktop, a terminal
install with: sudo apt install xvfb openbox xterm

Run that line on the host and try again. The CLI knows apt, dnf, zypper, pacman and apk, and on Enterprise Linux it adds epel-release when the window manager has to come from EPEL.

If you would rather not install anything, and you are logged in to a desktop on that machine, attach to it instead:

bin/robin gui --attach auto workstation

3. Use it

Click into the picture and type. Keys map by character, so text comes out right whatever your local keyboard layout is. Pasting with your usual shortcut sends the local clipboard to the remote first, and text copied on the remote lands on your local clipboard while the page has focus.

The status tab at the top shows whether you are on Direct UDP or the SSH tunnel, along with the picture size, frame rate and bitrate. It hides itself after a moment; move the pointer to the top edge to bring it back.

Muted at first. The page starts muted, because browsers only autoplay silent video. Click the speaker in the status tab to hear the session, and click it again after a reload.

The full screen button also asks the browser for keyboard lock where the browser supports it, so shortcuts such as Ctrl+W and Alt+Tab go to the remote desktop instead of closing your tab or switching your local windows.

4. Leave it, or end it

Press Ctrl+C in the terminal, or End session in the status tab. The CLI tells the agent goodbye, the agent stops the display, the desktop and everything else it started, and its run directory on the host is removed. The page shows “Session ended”.

To leave the desktop running instead, click Disconnect, keep desktop in the status tab. The CLI exits and the host keeps a desktop Robin started for 8 hours (--keep sets how long); an attached one is kept only when you name a --keep. Run the same command again to pick it up where you left it:

# resumes the kept desktop
bin/robin gui alice@build-box

# what the host keeps, and until when
bin/robin ls alice@build-box

# end it without opening it
bin/robin end alice@build-box

A dropped network keeps the desktop too: the page says Reconnecting, and the CLI redials until it is back. See Kept sessions.

Closing the browser tab does not end the session; reload it, or reopen the same link (from your browser’s history, or the one printed with --no-browser), and you are back where you were. Only one browser can hold a session at a time, so a second tab is refused until the first one closes.

When something goes wrong

Run the same command with -v. The CLI then logs each step to stderr, along with the agent’s own log from the host: what the probe found, which encoder was picked and why, and why a picked GPU encoder fell back to software. A session without sound says why even without -v.

bin/robin gui -v alice@build-box

If the CLI cannot open a browser (on a machine with no desktop, say), it prints open this URL in your browser: followed by the link. With --no-browser it prints only the link, on stdout, and leaves opening it to you.
